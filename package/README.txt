AA Map Editor for ArcheAge 10.x
===============================

1. Open editor-config.txt and set client_folder (your 10.x client) and database
   (the compact.sqlite3 of an AAEmu server).
2. Double-click "Start Editor.cmd". Save with Ctrl+S.
3. To put your edits into the client: close the game, back up game_pak once, then run
   "Install Edits Into Client.cmd". "Undo Last Install.cmd" reverts it.

Full instructions (controls, every tool, server side): MANUAL.md

AA Map Editor for ArcheAge 10.x
===============================

1. Open editor-config.txt and set client_folder (your 10.x client) and database
   (the compact.sqlite3 of an AAEmu server).
2. Double-click "Start Editor.cmd".

No game files are included. Edits are saved under the save_folder (default: saves\),
never into your client. Copy the saved cell files into a client/server yourself.

Controls: hold right mouse to look, WASD / Space / Ctrl to fly (Shift = fast),
left click selects, F focuses, Ctrl+S saves, Ctrl+Z / Ctrl+Y undo / redo, M teleport map.
